# The Meeting That Should Have Been One Line

Entry for make.fun's "The Meeting That Should Have Been One Line" bounty ($2, winner-take-all).

## The entry

> We're doing the thing, it starts Monday, bring your own laptop and stop asking whose idea it was.

97 characters. One sentence that is the whole meeting: the decision, the start date, and the logistics — with the sting on the last words, the quiet truth of every pointless meeting: the room was never deciding anything, it was arguing over credit.

## How to run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
